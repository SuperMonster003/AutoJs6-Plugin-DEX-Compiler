# v1.0.0

###### 2026/08/08

* `تلميح` أول إصدار مستقر. غير فعال افتراضيًا بعد التثبيت; يجب تفعيله يدويًا في خيارات المطور في AutoJs6, انظر قسم "التثبيت والاستخدام" في README لمعرفة الخطوات
* `ميزة` يعمل كملحق خارجي لترجمة DEX في AutoJs6: عندما يحمّل السكربت ملف JAR عبر `runtime.loadJar()`, يمكن لهذا الملحق تنفيذ الترجمة من JAR إلى DEX بدلًا من المترجم المدمج
* `ميزة` تعمل الترجمة في بيئة معزولة خاصة داخل عملية الملحق نفسها, بمعزل عن AutoJs6; وإذا فشل الملحق أو كان غير متاح, يعود AutoJs6 إلى مترجمه المدمج مرة واحدة على الأكثر
* `ميزة` يتحقق بصرامة قبل الترجمة من حجم JAR المدخل و SHA-256 وبنية ZIP وأسماء المدخلات ومحتوى الأصناف, ويرفض المدخلات المشوهة أو المتجاوزة للحدود أو المعدلة
* `ميزة` يدعم وضعي الترجمة DEBUG و RELEASE ومخرجات multi-dex و minApi من 24 إلى 36; المخرجات هي ZIP من `classes*.dex` مرقمة تسلسليًا مع الإبلاغ عن الحجم الفعلي و SHA-256
* `ميزة` متوافق مع أجهزة Android 7.0 (API 24) فما فوق; يستخدم API 26+ الأداة D8Command بينما يستخدم API 24/25 تلقائيًا مسار توافق D8 CLI
* `ميزة` يتواصل فقط مع AutoJs6 بتوقيع مطابق (محمي بإذن `org.autojs.permission.PLUGIN`) ولا يطلب أذونات شبكة أو تخزين
* `ميزة` تنفيذ JVM خالص بملف universal APK واحد يغطي جميع بنى الأجهزة; يأتي مع واجهة و README وتعليمات داخل التطبيق بعشر لغات
* `إصلاح` دعم تعليقات أرشيف ZIP/JAR القياسية والمحدودة عندما ينتهي الطول المعلن تمامًا عند حد الملف, مع استمرار رفض سجلات EOCD الملتبسة والأطوال غير المتسقة والبيانات اللاحقة
* `إصلاح` الحفاظ على محرك D8 المضمّن ومزودي خدماته في إصدارات Release المصغرة كي تتمكن ملفات APK الإنتاجية من ترجمة مدخلات JAR
* `تحسين` يحد التجميع المتوازي الداخلي في D8 بخيطي عمل لتقليل ذروة الذاكرة عند التجميع البارد لملفات JAR الكبيرة دون تغيير المخرجات أو دلالات ذاكرة التخزين المؤقت
* `تبعية` يتضمن مكتبة Google R8 بإصدار 8.13.17 (توفر مترجم D8)
