# v1.0.0

###### 2026/08/08

* `Подсказка` Первый стабильный выпуск. После установки по умолчанию неактивен; его нужно включить вручную в параметрах разработчика AutoJs6, шаги см. в разделе «Установка и использование» README
* `Функция` Работает как внешний плагин компилятора DEX для AutoJs6: когда скрипт загружает JAR через `runtime.loadJar()`, этот плагин может выполнить компиляцию JAR в DEX вместо встроенного компилятора
* `Функция` Компиляция выполняется в приватной песочнице внутри собственного процесса плагина, изолированно от AutoJs6; при сбое или недоступности плагина AutoJs6 не более одного раза возвращается к встроенному компилятору
* `Функция` Перед компиляцией строго проверяет размер, SHA-256, структуру ZIP, имена записей и содержимое классов входного JAR, отклоняя некорректный, превышающий лимиты или подменённый вход
* `Функция` Поддерживает режимы компиляции DEBUG и RELEASE, вывод multi-dex и minApi от 24 до 36; вывод — последовательно нумерованный ZIP `classes*.dex` с отчётом о фактическом размере и SHA-256
* `Функция` Совместим с устройствами на Android 7.0 (API 24) и выше; API 26+ использует D8Command, а API 24/25 автоматически используют совместимый путь D8 CLI
* `Функция` Взаимодействует только с идентично подписанным AutoJs6 (под защитой разрешения `org.autojs.permission.PLUGIN`) и не запрашивает разрешений на сеть и хранилище
* `Функция` Чистая JVM-реализация с единым universal APK для всех архитектур устройств; поставляется с интерфейсом, README и встроенными инструкциями на 10 языках
* `Исправление` Поддержаны стандартные ограниченные комментарии архивов ZIP/JAR, если объявленная длина точно заканчивается на границе файла; неоднозначные EOCD, несогласованные длины и хвостовые данные по-прежнему отклоняются
* `Исправление` В минифицированных Release-сборках сохраняются встроенный движок D8 и его поставщики сервисов, чтобы производственный APK мог компилировать входные JAR
* `Зависимость` Включает библиотеку Google R8 8.13.17 (предоставляющую компилятор D8)
