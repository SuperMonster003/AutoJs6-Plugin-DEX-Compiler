# Компилятор DEX AutoJs6

Этот плагин компилирует один нормализованный JAR с помощью D8 8.13.22 и возвращает ограниченный ZIP с последовательными записями `classes*.dex`.

Плагину требуется сборка хоста 5270 или новее и Android API 24 или новее.

Ограничения безопасности и работы:

- Привязать службу компилятора может только хост AutoJs6 с той же подписью.
- Перед компиляцией повторно проверяются размер, SHA-256, структура ZIP, пути записей, коэффициенты сжатия и файлы class.
- Вывод ограничен 16 MiB и 64 последовательными индексированными записями DEX.
- Отмена прекращает публикацию вывода, но D8 может работать до возврата текущей компиляции.
- Хост независимо проверяет возвращенный DEX ZIP перед кешированием или загрузкой.
- Плагин не запрашивает разрешения на хранилище или сеть.
