# AutoJs6 DEX 編譯器

此插件使用 D8 8.13.22 編譯單一正規化 JAR, 並傳回包含連續 `classes*.dex` 項目的受限 ZIP.

插件需要宿主建置版本 5270 或更新版本, 並需要 Android API 24 或更新版本.

安全和執行限制:

- 僅具有相同簽章的 AutoJs6 宿主可以繫結編譯器服務.
- 編譯前會再次檢查輸入大小, SHA-256, ZIP 框架, 項目路徑, 壓縮比和 class 檔案.
- 輸出上限為 16 MiB, 且最多包含 64 個連續索引 DEX 項目.
- 取消會停止發佈輸出, 但 D8 可能繼續執行到目前編譯返回.
- 宿主會在快取或載入前獨立驗證傳回的 DEX ZIP.
- 插件不要求儲存或網路權限.
