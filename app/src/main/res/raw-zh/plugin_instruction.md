# AutoJs6 DEX 编译器

此插件使用 D8 8.13.17 编译单个规范化 JAR, 并返回包含连续 `classes*.dex` 条目的有界 ZIP.

插件需要宿主构建版本 5270 或更高版本, 并需要 Android API 24 或更高版本.

安全和运行限制:

- 仅具有相同签名的 AutoJs6 宿主可以绑定编译器服务.
- 编译前会再次检查输入尺寸, SHA-256, ZIP 帧结构, 条目路径, 压缩比和 class 文件.
- 输出最大为 16 MiB, 且最多包含 64 个连续索引 DEX 条目.
- 取消会停止发布输出, 但 D8 可能继续运行到当前编译返回.
- 宿主会在缓存或加载前独立验证返回的 DEX ZIP.
- 插件不请求存储或网络权限.
