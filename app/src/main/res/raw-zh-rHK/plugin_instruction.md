# AutoJs6 DEX 編譯器

此插件使用 D8 8.13.22 編譯單個規範化 JAR, 並傳回包含連續 `classes*.dex` 項目的有界 ZIP.

插件需要宿主構建版本 5270 或更高版本, 並需要 Android API 24 或更高版本.

安全和運行限制:

- 僅具有相同簽名的 AutoJs6 宿主可以綁定編譯器服務.
- 編譯前會再次檢查輸入大小, SHA-256, ZIP 幀結構, 項目路徑, 壓縮比和 class 檔案.
- 輸出最大為 16 MiB, 且最多包含 64 個連續索引 DEX 項目.
- 取消會停止發佈輸出, 但 D8 可能繼續運行到目前編譯傳回.
- 宿主會在快取或載入前獨立驗證傳回的 DEX ZIP.
- 插件不請求儲存或網絡權限.
