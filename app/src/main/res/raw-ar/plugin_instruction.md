# مترجم DEX في AutoJs6

يترجم هذا المكون ملف JAR واحدا بعد تطبيعه باستخدام D8 8.13.22 ويعيد ZIP محدودا يحتوي على مدخلات `classes*.dex` متصلة.

يتطلب المكون إصدار المضيف 5270 أو أحدث و Android API 24 أو أحدث.

حدود الأمان والتشغيل:

- يمكن لمضيف AutoJs6 ذي التوقيع نفسه فقط ربط خدمة الترجمة.
- يعاد فحص الحجم و SHA-256 وبنية ZIP ومسارات المدخلات ونسب الضغط وملفات class قبل الترجمة.
- يقتصر الخرج على 16 MiB و 64 مدخلا متصلا ومفهرسا من DEX.
- يوقف الإلغاء نشر الخرج, لكن D8 قد يستمر حتى عودة عملية الترجمة الحالية.
- يتحقق المضيف بشكل مستقل من DEX ZIP المعاد قبل التخزين المؤقت او التحميل.
- لا يطلب المكون إذن تخزين أو شبكة.
