# مترجم DEX في AutoJs6

تتيح هذه الإضافة لـ AutoJs6 ترجمة ملفات JAR بواسطة D8 8.13.22 في عملية منفصلة. وهي تدعم `runtime.loadJar()` ومسار classpath المرتب وقت الترجمة الذي تستخدمه `runtime.loadJarWithClasspath()`.

## قبل التفعيل

- الإضافة معطلة افتراضيا. تثبيت ملف APK وحده لا يغير سلوك AutoJs6.
- يلزم AutoJs6 build 5270 أو أحدث و Android 7.0 (API 24) أو أحدث. تتطلب نقطة إدخال classpath إصدار مضيف مقترنا أحدث.
- يجب أن تكون توقيعات AutoJs6 والإضافة متطابقة. لا يمكن اختيار إضافة ذات توقيع مختلف.

## تفعيل الإضافة

1. ثبت مضيف AutoJs6 المتوافق أو قم بترقيته, ثم ثبت ملف APK الخاص بهذه الإضافة.
2. في AutoJs6, افتح الإعدادات > حول التطبيق والمطور, ثم اضغط مطولا على أيقونة التطبيق للدخول إلى خيارات المطور.
3. افتح DEX compiler > Raw JAR compiler provider.
4. اختر مكون خدمة هذه الإضافة وأكد الاختيار.

يعني ملخص provider أن الإضافة محددة; ومع ذلك قد تستخدم عملية تحميل بعينها نتيجة مخزنة مؤقتا أو المسار الاحتياطي المدمج.

## الاستخدام والاستعادة

استدع `runtime.loadJar()` أو `runtime.loadJarWithClasspath()` كالمعتاد. لا تضيف الإضافة أي كائن عام في JavaScript ولا يمكنها قراءة المسار الأصلي للبرنامج النصي.

إذا كانت الإضافة غير متاحة أو مشغولة أو انتهت مهلتها أو فشلت في الترجمة أو أعادت خرجا غير صالح, يعيد AutoJs6 المحاولة للطلب نفسه بالمترجم المدمج مرة واحدة على الأكثر. الإلغاء المتعمد لا يشغل المسار الاحتياطي. لتعطيل الإضافة, اختر Built-in D8/dx في صفحة خيارات المطور نفسها ثم أعد تشغيل AutoJs6; لا حاجة إلى إزالة المضيف أو مسح بياناته.

## الأمان والحدود

- لا يمكن ربط خدمة المترجم إلا من مضيف AutoJs6 ذي التوقيع نفسه.
- يجري فحص الحجم و SHA-256 وبنية ZIP ومسارات المدخلات ونسب الضغط وملفات class قبل الترجمة; ويتحقق AutoJs6 أيضا بصورة مستقلة من DEX ZIP قبل التخزين المؤقت أو التحميل.
- يقتصر الخرج على 16 MiB و 64 مدخلا متصلا من `classes*.dex`.
- لا تطلب الإضافة إذن تخزين أو شبكة. وهي تنفذ ترجمة D8 فقط, من دون تقليص R8 أو تشويشه.

عند الإبلاغ عن مشكلة, أرفق build الخاص بـ AutoJs6 وإصدار الإضافة و Android API و ABI الجهاز وخطوات إعادة المشكلة وخطأ البرنامج النصي كاملا. احذف المسارات الخاصة والمحتوى الحساس من السجلات قبل مشاركتها.
