# AutoJs6 DEX 컴파일러

이 플러그인은 AutoJs6가 별도 프로세스에서 D8 8.13.22로 JAR을 컴파일하도록 합니다. `runtime.loadJar()`와 `runtime.loadJarWithClasspath()`가 사용하는 순서가 지정된 컴파일 타임 classpath를 지원합니다.

## 활성화하기 전에

- 플러그인은 기본적으로 비활성화되어 있습니다. APK를 설치하는 것만으로는 AutoJs6 동작이 바뀌지 않습니다.
- AutoJs6 build 5270 이상과 Android 7.0 (API 24) 이상이 필요합니다. classpath 진입점에는 더 최신의 페어링된 호스트 build가 필요합니다.
- AutoJs6와 플러그인의 서명이 같아야 합니다. 서명이 다른 플러그인은 선택할 수 없습니다.

## 플러그인 활성화

1. 호환되는 AutoJs6를 설치하거나 업그레이드한 다음 이 플러그인 APK를 설치합니다.
2. AutoJs6에서 설정 > 앱 및 개발자 정보를 열고 앱 아이콘을 길게 눌러 개발자 옵션으로 이동합니다.
3. DEX compiler > Raw JAR compiler provider를 엽니다.
4. 이 플러그인의 서비스 컴포넌트를 선택하고 확인합니다.

provider 요약은 플러그인이 선택되었다는 뜻입니다. 특정 로드에서는 캐시된 결과나 내장 폴백을 사용할 수도 있습니다.

## 사용 및 복구

평소처럼 `runtime.loadJar()` 또는 `runtime.loadJarWithClasspath()`를 호출하세요. 플러그인은 JavaScript 전역 객체를 추가하지 않으며 원래 스크립트 경로를 읽을 수도 없습니다.

플러그인을 사용할 수 없거나, 사용 중이거나, 시간 초과 또는 컴파일 실패가 발생하거나, 잘못된 출력을 반환하면 AutoJs6는 같은 요청을 내장 컴파일러로 최대 한 번 다시 시도합니다. 명시적인 취소는 폴백을 실행하지 않습니다. 플러그인을 비활성화하려면 같은 개발자 옵션 화면에서 Built-in D8/dx를 선택한 뒤 AutoJs6를 다시 시작하세요. 호스트 제거 또는 데이터 삭제는 필요하지 않습니다.

## 안전 및 제한

- 동일한 서명의 AutoJs6 호스트만 컴파일러 서비스에 바인딩할 수 있습니다.
- 컴파일 전에 입력 크기, SHA-256, ZIP 구조, 항목 경로, 압축률 및 class 파일을 검사하며, AutoJs6도 캐시 또는 로드 전에 반환된 DEX ZIP을 독립적으로 검사합니다.
- 출력은 16 MiB와 연속된 `classes*.dex` 항목 64개로 제한됩니다.
- 저장소 또는 네트워크 권한을 요청하지 않습니다. D8 컴파일만 수행하며 R8 축소나 난독화는 수행하지 않습니다.

문제를 보고할 때는 AutoJs6 build, 플러그인 버전, Android API, 기기 ABI, 재현 단계 및 전체 스크립트 오류를 포함하세요. 로그를 공유하기 전에 개인 경로나 민감한 내용을 제거하세요.
