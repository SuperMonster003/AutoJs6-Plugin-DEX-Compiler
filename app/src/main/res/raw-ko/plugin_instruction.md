# AutoJs6 DEX 컴파일러

이 플러그인은 정규화된 단일 JAR을 D8 8.13.17로 컴파일하고 연속된 `classes*.dex` 항목이 포함된 제한 ZIP을 반환합니다.

호스트 build 5270 이상과 Android API 24 이상이 필요합니다.

안전 및 실행 제한:

- 동일한 서명의 AutoJs6 호스트만 컴파일러 서비스에 바인딩할 수 있습니다.
- 컴파일 전에 입력 크기, SHA-256, ZIP 구조, 항목 경로, 압축률 및 class 파일을 다시 검사합니다.
- 출력은 16 MiB와 연속된 인덱스 DEX 항목 64개로 제한됩니다.
- 취소하면 출력 게시가 중지되지만 D8은 현재 컴파일이 반환될 때까지 계속 실행될 수 있습니다.
- 호스트는 캐시하거나 로드하기 전에 반환된 DEX ZIP을 독립적으로 검증합니다.
- 저장소 또는 네트워크 권한을 요청하지 않습니다.
