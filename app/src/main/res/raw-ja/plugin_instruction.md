# AutoJs6 DEX コンパイラ

このプラグインは正規化済みの単一 JAR を D8 8.13.17 でコンパイルし, 連続する `classes*.dex` エントリを含む上限付き ZIP を返します.

ホスト build 5270 以降と Android API 24 以降が必要です.

安全性と運用上の制限:

- 同じ署名を持つ AutoJs6 ホストだけがコンパイラサービスをバインドできます.
- コンパイル前に入力サイズ, SHA-256, ZIP 構造, エントリパス, 圧縮率, class ファイルを再検証します.
- 出力は 16 MiB および連続する 64 個のインデックス付き DEX エントリまでです.
- キャンセルは出力の公開を停止しますが, D8 は現在のコンパイルが戻るまで動作を続ける場合があります.
- ホストはキャッシュまたはロードの前に返された DEX ZIP を独立して検証します.
- ストレージ権限とネットワーク権限は要求しません.
