# AutoJs6 DEX コンパイラ

このプラグインは AutoJs6 の JAR を別プロセスで D8 8.13.22 によりコンパイルします. `runtime.loadJar()` と, `runtime.loadJarWithClasspath()` が使う順序付きコンパイル時 classpath に対応します.

## 有効にする前に

- プラグインは既定で無効です. APK をインストールしただけでは AutoJs6 の動作は変わりません.
- AutoJs6 build 5270 以降と Android 7.0 (API 24) 以降が必要です. classpath エントリポイントには, より新しい対応ホスト build が必要です.
- AutoJs6 とプラグインの署名は同一でなければなりません. 署名が異なるプラグインは選択できません.

## プラグインを有効にする

1. 対応する AutoJs6 をインストールまたは更新してから, このプラグイン APK をインストールします.
2. AutoJs6 で 設定 > アプリと開発者について を開き, アプリアイコンを長押ししてデベロッパーオプションに入ります.
3. DEX compiler > Raw JAR compiler provider を開きます.
4. このプラグインのサービスコンポーネントを選択して確定します.

provider の概要はプラグインが選択済みであることを示します. 個々のロードではキャッシュ結果や内蔵フォールバックが使われる場合もあります.

## 使用と復旧

通常どおり `runtime.loadJar()` または `runtime.loadJarWithClasspath()` を呼び出してください. プラグインは JavaScript グローバルを追加せず, 元のスクリプトパスも読み取れません.

プラグインが利用不能, ビジー, タイムアウト, コンパイル失敗, または無効な出力を返した場合, AutoJs6 は同じ要求を内蔵コンパイラで最大 1 回再試行します. 明示的なキャンセルではフォールバックしません. 無効にするには, 同じデベロッパーオプション画面で Built-in D8/dx を選択し AutoJs6 を再起動してください. ホストのアンインストールやデータ消去は不要です.

## 安全性と制限

- 同じ署名の AutoJs6 ホストだけがコンパイラサービスをバインドできます.
- コンパイル前に入力サイズ, SHA-256, ZIP 構造, エントリパス, 圧縮率, class ファイルを検査し, AutoJs6 もキャッシュやロードの前に返された DEX ZIP を独立して検査します.
- 出力は 16 MiB, 連続する `classes*.dex` エントリ 64 個までです.
- ストレージ権限とネットワーク権限は要求しません. D8 コンパイルのみを行い, R8 の縮小や難読化は行いません.

問題を報告する際は AutoJs6 build, プラグイン版, Android API, 端末 ABI, 再現手順, スクリプトの完全なエラーを添えてください. ログを共有する前に私的なパスや機密情報を除去してください.
